# 牛尾环九轴标注台 · Cattle Tail-Ring 9-Axis Annotator

面向牛尾佩戴式传感环（九轴 IMU：三轴加速度 + 三轴角速度 + 三轴磁场，另含温度与运动计数）的**离线单页行为标注工具**。双击 HTML 即可在 Chrome / Edge 中使用，全程不联网、无需安装任何环境，数据不出本机。

## 功能特性

- **真实数据驱动**：选择 JSON → 解析 → 解码 IMU → 绘制真实曲线，无内置演示数据
- **九轴 + 温度/运动曲线**：加速度、角速度、磁场各 XYZ 分面板显示，悬停读取每通道实际数值
- **统一播放头**：一次播放，竖线在视频与九轴时间轴上同步滑动；拖动任一侧两侧同跳
- **视频对齐**：按文件名时间 / 角上时间单帧锚点 / 手动钉住 三种对齐方式，偏移量记入导出元数据
- **双遍标注法**：第一遍铺互斥状态（采食/行走/休息/点头），第二遍叠事件（爬跨/抬尾/撒尿/起卧/产犊等），支持区间拖边精修
- **判据来源 + 置信度**：每条标注记录"仅视频可辨 / 仅曲线可辨 / 两者皆可"与高中低置信度
- **双人盲标 IRR**：载入两份独立工程，按区间 IoU 与点事件容差计算事件级 F1 与逐帧 Cohen's κ
- **导出**：带元数据头的 CSV、BORIS 兼容表、工程文件（断点续标）、事件元数据
- **导出前自检**：结束早于开始、超出数据范围、短于最短时长、视频未对齐等完整性检查

## 输入数据格式

设备下载的 JSON，字段约定：

```json
{
  "version": 1,
  "device": "546C50CA07EF",
  "create_time": 1781789444565,
  "imu": "<base64 二进制，按 version 定帧长 18/20/22 字节，含 9 通道 int16>",
  "temperature": "<base64 uint16 分钟桶，可选>",
  "motion": "<base64 uint16 运动计数桶，可选>"
}
```

配套视频为同时间段 MP4（浏览器需能解码；H.265/HEVC 或监控 PS 封装需先用 FFmpeg 重封装为 `hvc1` + faststart，或转码 H.264）。

## 快速开始

1. 双击打开 HTML（推荐 Chrome / Edge）
2. 顶栏填 **标注者** 与 **协议版本**
3. 「打开九轴 JSON」选数据文件 → 「打开视频 MP4」选同段录像
4. 三选一完成一次对齐 → 分两遍标注 → 导出前自检 → 导出 CSV / 保存工程

详细流程见《牛尾环标注使用指南.md》；行为判定标准见《牛行为标注范围与操作性定义.md》。
