# 牛尾环九轴标注台

**离线单页。双击打开，给牛尾传感环的九轴记录打行为标签。数据留在本机。**

Chrome 或 Edge · 不安装 · 不联网

</div>

这是一份 HTML 标注页，不是 [COWMATA 桌面版](https://github.com/zxq309/COWMATA-Pro)。桌面版有安装包和模型辅助；这一页只做人工标注。

## 开始

1. 双击 [`牛尾环_九轴标注台_截图式真实数据版.html`](牛尾环_九轴标注台_截图式真实数据版.html)。
2. 顶栏填写标注者和协议版本。
3. 打开九轴 JSON，再打开同一时段的视频。
4. 对齐一次时间，然后标注。导出前先看自检。

同一目录里还有较早的 [`牛尾环_九轴标注台.html`](牛尾环_九轴标注台.html)，也可以双击打开。操作顺序见 [使用指南](牛尾环标注使用指南.md)。每个标签怎么判，见 [行为定义](牛行为标注范围与操作性定义.md)。

浏览器打不开的录像（常见是 H.265/HEVC，或监控用的 PS 封装）先在本机转成 H.264。这个页面不调用 FFmpeg。静止时加速度读数明显偏离 1 g，先按使用指南改加速度标度，再开始标注。

## 这一页做什么

| | |
|---|---|
| 播放 | 视频和九轴共用一个播放头，倍速 0.25×、0.5×、1×、2×、4× |
| 对齐 | 按文件名时间、画面角上的时间，或手动钉住。偏移写进导出 |
| 标签 | 状态区间和点事件分开。每条可选判据来源和置信度 |
| 对照 | 两份工程按区间 IoU 和点事件容差算事件级 F1，并给逐帧 Cohen's κ。设备或 `create_time` 不一致时不计算 |
| 导出 | 带表头的 CSV、工程文件，以及一份 BORIS 风格列的聚合 CSV。聚合表供下游读取，不能导回 BORIS |

输入是设备导出的 JSON：`version`、`device`、`create_time`，以及 base64 的 `imu`。有 `temperature` 或 `motion` 时，页面会多画出对应面板。没有 JSON，就没有曲线。

## 快捷键

焦点在输入框里时，这些按键不触发。

| 键 | 作用 |
|---|---|
| 空格 | 播放 / 暂停 |
| `[` `]` | 逐帧 |
| ← → | 移动播放头，100 ms；按住 Shift 为 1 s |
| `+` `-` | 缩放 |
| `f` | 看全程 |
| `n` `p` | 跳到后一处 / 前一处更强的活动段 |
| `Esc` | 取消尚未结束的区间 |
| Delete、Backspace | 删除当前选中 |
| Ctrl+Z、Ctrl+S | 撤销、保存工程 |
| 标签上的单个按键 | 选中该标签 |

## 局限

- 页面不上传数据，也没有账号。两人盲标各自保存工程，再在同一台浏览器里对比。
- 打开同一份 JSON 时，未导出的标注会写进本机 localStorage，下次可选择恢复。这不是云端保存。
- 导出前会提示：结束早于开始、超出数据范围、短于最短时长、互斥状态重叠、状态空隙，以及视频未对齐。
