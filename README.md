# 牛尾环九轴标注台 · Cattle Tail-Ring 9-Axis Annotator

离线单页工具，用来给牛尾佩戴式传感环的九轴记录打行为标签。九轴是三轴加速度、三轴角速度和三轴磁场；JSON 里若带温度和运动计数，页面会一并画出。双击 HTML 即可在 Chrome 或 Edge 中使用，不安装环境，不联网，数据留在本机。

## 两分钟内第一次使用

1. 双击 `牛尾环_九轴标注台_截图式真实数据版.html`（推荐这份；根目录里的 `牛尾环_九轴标注台.html` 也可以双击打开）。
2. 顶栏填写**标注者**和**协议版本**。
3. 点「打开九轴 JSON」，选择设备导出的 JSON。页面只绘制该文件，没有内置演示曲线。
4. 点「打开视频 MP4」，选择同一时段的录像。
5. 完成一次时间对齐，再标注。导出前点自检，然后导出 CSV 或点「保存工程」。

连续操作见 `牛尾环标注使用指南.md`。各标签的判定标准见 `牛行为标注范围与操作性定义.md`。

浏览器不能解码的录像（常见是 H.265/HEVC，或监控用的 PS 封装）需要先在本机用 FFmpeg 重封装或转成 H.264，再打开。本页面不调用 FFmpeg。

## 输入

```json
{
  "version": 1,
  "device": "546C50CA07EF",
  "create_time": 1781789444565,
  "imu": "<base64，按 version 每帧 18/20/22 字节，含 9 通道 int16>",
  "temperature": "<base64 uint16 分钟桶，可选>",
  "motion": "<base64 uint16 运动计数桶，可选>"
}
```

## 页面里实际有的流程

- 对齐方式包括按文件名时间、画面角上时间的单帧锚点，以及手动钉住。偏移写入导出元数据。
- 状态标签与事件标签分成两层。页面自带的状态包括休息、行走等互斥区间；事件包括抬尾、撒尿、起卧等，可与状态重叠。具体起止以《牛行为标注范围与操作性定义》和页面内定义为准。
- 每条标注可选判据来源（仅视频可辨 / 仅曲线可辨 / 两者皆可）和高、中、低置信度。
- 「对比两份标注」读取两份独立工程，按区间 IoU 和点事件时间容差给出事件级 F1，并给出逐帧 Cohen's κ。两份工程的设备或 `create_time` 不一致时，页面拒绝计算。
- 导出带表头的 CSV、工程文件，以及一份 BORIS 风格列的聚合 CSV。聚合 CSV 的按钮说明写明：供下游读取，不保证能直接导回 BORIS。
- 导出前检查结束早于开始、超出数据范围、短于该标签最短时长、互斥状态重叠、状态空隙，以及视频未对齐。

## 快捷键

以下按键属于推荐页面，焦点在输入框里时不触发：

空格播放/暂停 · `[` `]` 逐帧 · 左右方向键移动播放头（100 ms，按住 Shift 为 1 s）· `+` / `-` 缩放 · `f` 看全程 · `n` / `p` 跳到后一处 / 前一处更强的活动段 · `Esc` 取消尚未结束的区间 · 标签上设定的单个按键用来选中该标签 · Delete 或 Backspace 删除当前选中 · Ctrl+Z 撤销 · Ctrl+S 保存工程。

## 局限

- 没有 JSON 就没有曲线，页面不提供样例数据。
- 温度和运动计数缺席时，对应面板不出现。
- 聚合 CSV 不是 BORIS 工程文件。
- 打开同一份 JSON 时，页面会把标注写进本机 localStorage。若有尚未导出的记录，会询问是否恢复。这不是云端保存。
- 页面不上传数据，也没有账号或协作服务器。两人盲标需要各自保存工程，再在同一台浏览器里做对比。
